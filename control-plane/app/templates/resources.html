Cloud Cost Advisory Optimized
THEDAL is architected to minimize AWS expenses while providing full multi-host enterprise emulation.
  • Zero NAT Gateway Policy: Saves ~$32+/month by utilizing Squid proxy on Bastion.
  • Single Public IPv4: Only Bastion allocates a public IPv4 address.
  • Stopping vs. Destroying:
    • Stopping EC2: Halts hourly compute charges; attached EBS disk storage charges continue.
    • Terraform Destroy: Terminates compute and deletes EBS volumes, eliminating all charges.
Operator Guidance: When completing testing sessions, execute Destroy Lab in Operations to avoid ongoing storage charges.
