AWS Resource & Cost Advisory Architecture Cost Optimized
SOCForge is engineered to minimize cloud expenses while providing a complete multi-host enterprise testing ground.
  • Zero NAT Gateway Policy: Saves ~$32+/month by utilizing the forward Squid proxy on the Bastion jumpbox.
  • Single Public IPv4: Only the Bastion jumpbox allocates a public IP, avoiding excess IPv4 reservation fees.
  • Stopping vs. Destroying:
    • Stopping EC2: Stops hourly compute charges; attached EBS disk storage charges (~$0.10/GB/month) continue.
    • Terraform Destroy: Terminates compute and deletes attached EBS volumes completely, eliminating all recurring charges.
Operator Tip: When you are finished with a training lab for the day, use Destroy Environment in the Operations Console to prevent unexpected cloud billing.
