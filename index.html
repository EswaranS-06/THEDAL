Foundation

Why THEDAL Exists

Most cybersecurity training relies either on passive, static log dumps or artificial CTF challenges that lack real enterprise noise, genuine process trees, and live telemetry pipelines.

Live Cloud Infrastructure

Deploys a dedicated 5-host AWS VPC with an enterprise SIEM cluster, instrumented Windows Server endpoint, Linux web servers, and adversary emulation hosts.

Real Multi-Source Telemetry

Observe attacks propagating across HTTP requests, Docker container logs, Linux `auditd` syscalls, Windows Sysmon process lineages, and PowerShell ScriptBlocks.

Zero NAT Cost Architecture

Eliminates AWS NAT Gateway expenses (~$32+/month) by routing private subnet outbound package management through a hardened forward proxy on the Bastion jumpbox.

Deployment

Getting Started with THEDAL

Choose between a dedicated local Linux VM (recommended for full compatibility) or a Docker container.

Automated Setup with Universal Installer

Run the interactive installer on Debian 13 / Ubuntu 22.04+ to verify prerequisites, configure AWS credentials, and launch the Control Plane.

# 1. Clone repository git clone https://github.com/EswaranS-06/THEDAL.git cd THEDAL # 2. Run universal installer chmod +x install.sh ./install.sh

Manual Deployment Steps

# 1. Verify AWS credentials aws sts get-caller-identity # 2. Deploy AWS infrastructure make deploy # 3. Generate dynamic inventory & provision make inventory make provision # 4. Launch Control Plane UI make control-plane # Open: http://127.0.0.1:8080

Docker Compose Deployment

Mount your AWS credentials and local SSH key into the containerized Control Plane.

# 1. Build and run container docker compose up -d # 2. Access Control Plane # http://127.0.0.1:8080

Security Considerations

The Control Plane binds strictly to 127.0.0.1:8080. Never expose port 8080 publicly to 0.0.0.0 without authentication. AWS credentials and SSH keys remain mounted as read-only volumes.

Cloud Safety

AWS Cost & Safety Controls

Engineered from day one to eliminate surprise cloud billing and enforce strict operational guardrails.

Zero NAT Gateway

AWS NAT Gateways incur ~$32+/month flat fee plus data transfer. THEDAL completely eliminates NAT Gateways by routing outbound updates via the Bastion forward proxy.

Single Public IPv4

Only the Bastion host receives an Elastic IPv4 address. All SOC workloads, targets, and simulation engines reside on private subnets behind security groups.

Safe Teardown

Execute make destroy when finishing training sessions. Destructive actions require explicit confirmation phrases to prevent accidental deletion.
