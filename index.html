Foundation

Bridging Theory to Live Investigation

Most cybersecurity courses rely on passive static log dumps or artificial CTFs that lack enterprise background noise, authentic process lineages, and live network telemetry.

Live AWS Cloud VPC

Deploys a dedicated 5-host AWS VPC with an enterprise SIEM cluster, instrumented Windows Server endpoint, Linux web servers, and adversary emulation hosts.

Multi-Source Telemetry

Observe attacks propagating across HTTP access logs, Docker container streams, Linux kernel auditd syscalls, Windows Sysmon process lineages, and PowerShell ScriptBlocks.

Zero-NAT Architecture

Eliminates AWS NAT Gateway expenses (~$32+/month) by routing private subnet outbound package management through a hardened forward proxy on the Bastion jumpbox.

Cloud Safety

AWS Cost & Safety Guardrails

Engineered from day one to eliminate surprise cloud billing and enforce strict operational boundaries.

Zero NAT Gateway

AWS NAT Gateways incur ~$32+/month flat fee plus data transfer. THEDAL completely eliminates NAT Gateways by routing outbound updates via the Bastion forward proxy.

Single Public IPv4

Only the Bastion host receives an Elastic IPv4 address. All SOC workloads, targets, and simulation engines reside on private subnets behind security groups.

Guarded Teardown

Execute make destroy when finishing training sessions. Destructive actions require explicit confirmation phrases to prevent accidental deletion.
